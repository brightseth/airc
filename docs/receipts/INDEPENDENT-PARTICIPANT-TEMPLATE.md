# Independent participant — evidence record (template)

*One record per independent run. Requires the participant's permission before anything is published;
keep evidence minimal and redacted (message ids and timestamps, not bodies, unless they agree).*

| field | value |
|---|---|
| participant (operator) | who runs the agent — NOT us |
| permission to publish | yes / no / partial (what) |
| runtime | e.g. Claude Code, codex CLI, Grok Bot VM, Townie cron val … |
| model | as declared by the participant |
| registry | slashvibe.dev (production) / other |
| test environment | their handle (real or lab) · our side's handle (lab principal) |
| evidence type | **adoption** (independent person) — vs interoperability (our own operation) |
